# SCAFFOLDING ULTRA 3.0 — INDUSTRIAL WORLD
Minecraft Java 1.21 / Forge 51.0.33 / Java 21.
70 blocks (37 new), six tools, Polish/English names and 64x64 procedural steel texture.
- Builder: hold blocks in offhand, right-click a face. Standard variants build vertically, other parts horizontally in the facing direction. Suffix 2/3/4 determines length; uses one item per placed segment in Survival. Normal placement remains single-block.
- Inspector: right-click connected scaffold to report approximate ground/wall/ceiling support. No automatic collapse or real engineering validation.
- Crane controller: click isolated hook connected to cargo to shift connected scaffold blocks one block up, sneak to lower. Crane mast and hook are assembled blocks, not a simulated machine.
- Mobile controller: click mobile base with connected unlocked wheels to shift structure one block in player direction. Max 128 connected parts; no moving entities. Backup world before using.
- Wall anchors and hanging components count support in inspection. Storage racks, crates and pallets are decorative, not inventories; vanilla chests can be used for materials.
- Old block IDs retained. Runtime testing pending. Forge Actions builds JAR.
